Day 4: Linux, Unix, and POSIX file systems.

One of the first things that helps build a Linux mental model is seeing how its file tree differs from Windows.

Windows commonly starts with separate roots such as `C:\` and `D:\`. Unix-like systems use one hierarchy starting at `/`, where disks and other filesystems can be mounted into the tree.

macOS follows the Unix-like model, with its own organization for system files, applications, user data, and mounted volumes.

The goal isn’t to memorize every directory. It’s to build a map in your head. Once you understand the layout, Linux paths start to feel less arbitrary.
